# 16 可接入 Home Assistant 的低价设备选型（按协议路线）

核对日期 2026-09-28。协议与 HA 集成方式按官方文档逐条核对（来源见第 10 节）；
价格是历史常见价区间，只用于判断档位。不少经典款已经停产或换代，
按型号找不到时，找"同类同协议"的替代品即可。

## 0. 结论先给

选设备的第一判据是"它进 HA 走哪条协议、用哪个集成"，
这决定 v2 MCP 能不能把它投影进 8 个动作 / 6 个字段。

```text
我们当前的运行方式：HA 容器跑在 Docker Desktop + Windows，USB/蓝牙没有直通

纯 WiFi              → 直接买，不需要额外硬件，最省事
纯 BLE              → 要一个 ESP32 当蓝牙代理，顺带覆盖 ESPHome 路线
Zigbee / 蓝牙 Mesh  → 要网关；可行路线是 米家多模网关2 + XiaomiGateway3(HACS)
Matter / Thread     → 配网依赖蓝牙，Thread 还要边界路由器，先不碰
华为配件             → HA 没有接入路径，先不碰
```

三条起步组合（除网关外，单件都在 150 内）：

```text
BLE 线   米家蓝牙温湿度计2（约 20~40）＋ ESP32 开发板（约 20~40）
WiFi 线  Yeelight 灯泡 / 米家台灯（约 40~170）＋ 小米智能插座3（约 50~60）
网关线   米家多模网关2（约 160~220，单件略超 150）＋ 米家/Aqara 传感器（约 30~60 一只）
```

## 1. 协议 → HA 集成 → 我们 MCP 的落点

| 协议 / 通道 | HA 怎么接 | 典型设备 | 在 v2 MCP 里的投影 |
| --- | --- | --- | --- |
| 纯 BLE | core `bluetooth` + `xiaomi_ble` / `inkbird` / `govee_ble` / `switchbot` / `bthome` | 温湿度计、体重秤、花盆、BLE 按钮、BLE 灯带 | 传感器 → `current`；灯带 → `power` + `level` + `set_brightness`；按钮/门磁落在 8 动作之外 |
| 纯 WiFi | core `yeelight` / `wiz` / `tplink` / `xiaomi_miio` / `tuya`；HACS `ha_xiaomi_home`（小米官方）、`SonoffLAN` | 灯泡、台灯、灯带、插座、窗帘、风扇、空调伴侣 | 灯 → `power` + `level` + `set_brightness`；插座 → `power`；窗帘 → `position`；空调伴侣 → `mode` + `target` |
| Zigbee | core `zha`（要协调器）；HACS `XiaomiGateway3`（米家多模网关，走局域网） | 传感器、开关、灯泡、窗帘（都要网关或协调器） | HA 暴露成标准实体后，投影规则与上面一致 |
| 蓝牙 Mesh | HA 的 `bluetooth` 集成明确不支持 mesh，必须走厂商网关 | 米家蓝牙 Mesh 灯泡、传感器 | 经多模网关 + XiaomiGateway3 进 HA，之后用同一套语义 |
| Matter / Thread | core `matter` + `thread` | 新一代灯、插座、传感器 | 投影同上，但配网成本高，暂缓 |
| ESPHome / DIY | core `esphome`（局域网原生 API） | ESP32 / ESP8266 + 任意传感器 | 按它暴露的实体投影；还能兼职蓝牙代理 |
| 红外 / 射频 | core `broadlink`（自带 climate 子域）；HACS `SmartIR` | Broadlink RM4 mini 等 | 传统空调/风扇可包成 climate → `set_mode` + `set_temperature`，回读天生不可靠 |

口径对照（v2 的 8 动作 / 6 字段）：

```text
动作  turn_on / turn_off / toggle / set_mode / set_temperature /
      set_percentage / set_brightness / set_position
字段  on / mode / target / level / position / current
```

设备品类与动作的对应关系，直接决定"买回来能不能进动作空间"：

```text
灯（WiFi / BLE 灯带）   power + level + set_brightness      进动作空间（色温/颜色不在 6 字段里）
插座（WiFi）            power                                进动作空间
风扇（WiFi）            power + set_percentage               进动作空间
窗帘（WiFi / Zigbee）   power + position                     进动作空间
空调伴侣（红外）         mode + target                        进动作空间，回读不可信
温湿度 / 人体 / 门磁     只读 current                        做观察与 check_goal，没有 execute_action
按钮 / 摄像头 / 门锁     没有对应动作                          落在 scoping，不作为首批采购
```

## 2. 纯蓝牙（BLE-only）路线

能买到的东西：电池类传感器是主力，执行器很少。

HA 官方 `xiaomi_ble` 与 `bluetooth` 文档里的硬事实：

```text
1. xiaomi_ble 监听设备广播，不唤醒、不轮询，省电；实体在收到第一次广播后才出现
2. 覆盖 MiBeacon 传感器 + MiScale 体重秤 + MiFlora 花盆传感器三类
3. 明确不支持小米 BLE Mesh 设备（mesh 必须走网关）
4. 部分设备（MiBeacon v4/v5）要用小米账号导入 bindkey
5. Bluetooth 集成只支持 BLE，蓝牙经典（音箱那类）不支持
6. 容器安装可以插 USB 蓝牙适配器；官方原文点名虚拟化实例更适合 Bluetooth proxy：
   "A Bluetooth proxy is particularly interesting to users who virtualize their instance,
    where the USB pass-through may cause additional problems."
7. 青萍自己的 qingping 集成也是纯 BLE、无云账号、无网关（官方原文：
   "directly over Bluetooth Low Energy. No cloud account or hub is required"），
   先决条件同为本地蓝牙或 ESPHome 蓝牙代理
```

| 经典设备 | 类型 | 历史价 | HA 集成 | 说明 |
| --- | --- | --- | --- | --- |
| 米家蓝牙温湿度计2（LYWSD03MMC） | 温湿度 | 20~40 | `xiaomi_ble` | 最值得先买；可刷 pvvx 固件调更新频率 |
| 米家温湿度计3（MJWSD05MMC） | 温湿度 | 40~70 | `xiaomi_ble` | 带屏款 |
| 秒秒测 MHO-C401、青萍 CGDK2 | 温湿度 | 40~100 | `xiaomi_ble`（要 bindkey） | 同属 Telink 方案 |
| 青萍 Temp RH M（CGG1/CGG3）、门磁 CGH1、人体 CGPR1、闹钟 CGD1 等 | 温湿度/门磁/人体 | 40~150 | `qingping`（纯 BLE，无云无网关） | 官方要求本地蓝牙或 ESPHome 代理；CGG1 也可走 `xiaomi_ble` |
| 花花草草监测仪（HHCCJCY01） | 土壤 | 40~70 | `xiaomi_ble`（Flower Care） | 经典款，可能已停产 |
| 小米体重秤2 | 体重/体脂 | 60~100 | `xiaomi_ble` | 广播式，非实时 |
| Inkbird IBS-TH2 | 温湿度/探针 | 60~100 | `inkbird` | 海外品牌，国内靠进口 |
| SwitchBot Bot | 机械按钮 | 90~140 | `switchbot` | 按老式开关；button 在 8 动作之外 |
| Govee BLE 灯带 | 灯带 | 100~200 | `govee_ble` | 海外渠道为主 |

为什么几乎没有"纯蓝牙台灯"：BLE 直连要保持配对，厂商做灯一般给 WiFi
或 BLE Mesh + 网关。想要"蓝牙灯"练手，走的是 Mesh + 网关那条线，
不是 BLE 直连。
BLE 设备怎么进本机 HA（电脑蓝牙 / ESP32 代理 / Theengs 网关）见
18 号文档《电脑蓝牙接入本机 HA 的可行性分析》。

## 3. 纯 WiFi 路线

本地直连（断网可用，前提是 HA 与设备同网段）：

```text
yeelight     Yeelight 系 WiFi 灯泡/灯带，能被自动发现
wiz          WiZ 灯和插座，配置里要开启 local connectivity
tplink       Kasa 老设备本地直连；新 Kasa/Tapo 要用 TP-Link 账号认证后本地访问
xiaomi_miio  老米家 WiFi 设备本地控制，要提取 token（含插座、台灯、风扇、空调伴侣）
```

云 / 混合通道：

```text
ha_xiaomi_home  小米官方 HACS 集成（XiaoMi/ha_xiaomi_home），覆盖 MIoT 设备，部分支持本地控制
tuya            官方云集成，要涂鸦开发者账号，白牌 WiFi 设备命中率最高
SonoffLAN       HACS，易微联固件走局域网，Sonoff Basic R3 很便宜
```

| 经典设备 | 类型 | 历史价 | HA 集成 | 说明 |
| --- | --- | --- | --- | --- |
| Yeelight 智能灯泡 1S / 彩光版 | 灯泡 | 40~70 | `yeelight` | 想测灯首选 |
| Yeelight 灯带 1S | 灯带 | 80~130 | `yeelight` | 亮度 + 颜色 |
| 米家台灯1S | 台灯 | 140~170 | `xiaomi_miio` | 官方 169，促销常到 150 内 |
| 米家床头灯2 | 床头灯 | 160~200 | `xiaomi_miio` | 略超 150 |
| 小米智能插座3 | 插座 | 50~60 | `xiaomi_miio` / `ha_xiaomi_home` | 想测开关首选 |
| 小米智能插座2 蓝牙网关版 | 插座 + BLE 网关 | 50~60 | `xiaomi_miio` | 经典款；自带的 BLE 网关不直接给 HA 用 |
| 小米空调伴侣2 | 红外 + 计量 | 150~170 | `xiaomi_miio` | 让传统空调变成 climate；状态是 HA 推的，回读不可信 |
| TP-Link Tapo P100 / P110 | 插座 | 50~90 | `tplink` | 海外便宜，国内型号渠道少 |
| WiZ 灯泡 / 插座 | 灯 / 插座 | 30~70 | `wiz` | 国内渠道少，海外很多 |
| 涂鸦白牌 WiFi 灯泡 / 插座 | 灯 / 插座 | 15~40 | `tuya`（云）/ localtuya | 最便宜，质量参差 |
| Sonoff Basic R3 | 通断模块 | 25~40 | HACS `SonoffLAN` 或刷 ESPHome | DIY 玩法多 |
| Broadlink RM4 mini | 红外遥控 | 120~160 | `broadlink`（自带 climate 子域） | 传统空调/风扇进 HA 的捷径 |

WiFi 路线的常见坑：

```text
1. 基本都是 2.4GHz，5GHz 配不上网
2. 大多数要先在厂商 App 里配网，再进 HA
3. 云集成依赖外网，云挂了设备就掉线
4. 小米 token 提取是经典门槛；用官方 ha_xiaomi_home 可以绕开大部分
```

## 4. Zigbee 与蓝牙 Mesh（需要网关）

这条线本身不贵，贵在"进门"：

```text
HA 的 ZHA 让 Zigbee 设备直连 HA，但需要一个协调器（USB 棒或网络协调器）
我们跑在 Docker Desktop 上，USB 直通基本不可用（usbipd 转发到容器也不稳）
可行路线：厂商网关走局域网进 HA —— XiaomiGateway3(HACS) 支持
          米家多模网关(3代)、米家多模网关2、Aqara Hub E1，默认固件即可
```

| 设备 | 角色 | 历史价 | 说明 |
| --- | --- | --- | --- |
| 米家多模网关2 | Zigbee + 蓝牙 Mesh 网关 | 160~220 | 走 XiaomiGateway3，本地控制；单件略超 150 |
| Aqara Hub E1 | Zigbee 网关 | 130~180 | XiaomiGateway3 明确支持 |
| 米家 / Aqara 门磁、人体、温湿度 | 传感器 | 30~80 | 挂网关下，进 HA 后走 `current` |
| Zigbee 灯泡 / 开关 | 执行器 | 30~80 | 挂网关下，走 `power` / `level` |
| USB 协调器（CC2652、ZBDongle 等） | ZHA 协调器 | 60~130 | 便宜但我们的环境用不了，暂不买 |

记住一条：`xiaomi_ble` 明确不支持 BLE Mesh，
米家蓝牙 Mesh 灯泡/传感器只有"网关 + XiaomiGateway3"或小米官方云集成两条路。
Zigbee 接入本机 HA 的五条路线（含 USB 棒 + usbipd、Z2M on Windows、
网络协调器）见 17 号文档《Zigbee 接入本机 HA 的可行性分析》。

## 5. Matter / Thread（先不买）

HA 官方文档写得清楚：

```text
1. Matter 设备配网过程中要用 Bluetooth（commissioning）
2. 配网要用 Home Assistant Companion App
3. Thread 设备必须要有 Thread 边界路由器（border router）
4. 纯 Thread 设备"requires border router"，不能用 WiFi 代替
```

国内 ≤150 的 Matter 设备存在（涂鸦系的灯/插座），但对我们这套
Docker Desktop 环境，配网要多一层蓝牙 + 手机 App，收益低。
等前三条线跑通再考虑。
本机跑 Matter 的具体障碍（IPv6 / NAT / 官方对 Container 的态度）见
19 号文档《Matter 设备与 ESP32 接入本机 HA》。

## 6. ESPHome / 蓝牙代理：最便宜的一条路

ESP32 开发板 20~40 元，ESP8266 更低。烧 ESPHome 后 HA 原生 API 直连，
不需要云，同时可以：

```text
1. 当 Bluetooth proxy，把 BLE 设备接进 HA —— 官方文档推荐的虚拟化方案
2. 接继电器/传感器，自己做灯、插座、温湿度节点
3. 当红外发射器（配 remote_transmitter），替代 Broadlink
```

这条线单件最便宜、覆盖面最广，建议和 BLE 设备一起买。

## 7. 华为：结论是不要在配件上花钱

检索结论（HA 官方集成 + GitHub 搜索）：

```text
HA 官方现存与华为相关的集成只有 huawei_lte：监控/控制华为 LTE 路由器、CPE
（历史上存在过 huawei_router，已被 HA 移除，文档页现在显示 "Removed integration"）
GitHub 搜 "huawei hilink home assistant"   → 只有 1 个仓库，是 E3372 4G 棒发短信的 add-on
GitHub 搜 "huawei smart home homeassistant" → 0 个结果
GitHub 搜 "harmonyos home assistant"        → 只有手表客户端、推送等，没有智能家居接入
```

华为智选 / 鸿蒙智联的配件（台灯、温湿度计、摄像头、门锁等）控制面走
智慧生活 App + 华为云，没有对外协议，也没有官方或成熟社区集成。
能进 HA 的"华为设备"只有两类：

```text
华为 LTE 路由器    huawei_lte 官方集成（监控信号/流量/短信），与智能家居控制无关
华为手机 / 平板    装 HA App 当控制端，属于客户端，不是被控设备
```

替代思路：华为智选里不少产品是 OEM（欧普、达伦、秒秒测等），
但这些产品的华为版固件是 HiLink，仍然进不了 HA；
要买就买同厂的非华为版，或者直接选米家 / Yeelight / 涂鸦这些
HA 已有集成的品牌。

## 8. 买回来怎么验收

```text
第一步  HA → 设置 → 设备与服务，能看到实体（BLE 设备先确认蓝牙适配器/代理已上线）
第二步  v2 MCP inspect_device 能看到它，六字段有值
第三步  有动作的设备 execute_action 写一次，verified=true
第四步  只读设备用 check_goal 当判定源（例如 <device>.current 的温度阈值）
```

买之前问四个问题：

```text
1. 它有 HA 集成吗？core 还是 HACS？
2. 协议要不要额外硬件？（BLE 要代理，Zigbee 要网关，红外要遥控器）
3. 它的语义落在 8 动作里，还是 scoping？（按钮/摄像头/门锁进不了动作空间）
4. 状态能不能读回？（BLE 广播可以，红外盲控不行）
```

## 9. 采购清单建议

优先级从高到低：

```text
① WiFi 线（最快见效，约 100~120 元）
   Yeelight 智能灯泡 + 小米智能插座3
   验收：灯 power/level/set_brightness、插座 power 全走通

② BLE + ESPHome 线（约 50~80 元）
   ESP32 开发板 + 米家蓝牙温湿度计2
   验收：温湿度计以 current 出现在 HA，ESP32 作为蓝牙代理可见

③ Zigbee / Mesh 线（约 200~280 元，可选）
   米家多模网关2 + 门磁/人体/温湿度
   验收：网关下挂设备被 XiaomiGateway3 本地暴露

不建议先买：华为配件、Matter/Thread 设备、需要 USB 协调器的 Zigbee 方案
```
