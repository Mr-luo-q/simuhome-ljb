# 生成图表.py 说明

## 功能

把《边界扫描结果.md》里的实测数字画成两张汇报图，避免正文堆表格。脚本不读外部数据文件，所有数值写在 `BOUNDARY` 常量和 `figure_training_summary` 里，改数字即可重画。

## 输入

无文件输入。数据来源为同目录上一级的《边界扫描结果.md》：

```text
BOUNDARY 每一行 = (标签, batch, num_generation, max_completion, 峰值显存GB, 步时秒)
训练结果      = 前 20 步 reward -1.04、后 20 步 -0.47、KL 0→0.02、峰值显存 22.7GB
```

## 输出

```text
img/grpo_memory_boundary.png    峰值显存随 rollout 规模变化，标 96GB 上限与每档步时
img/grpo_training_summary.png   250 步正式训练的 reward 前后对比 + KL/显存/利用率标注
```

## 运行

```bash
python img/生成图表.py
```

依赖 matplotlib，中文用微软雅黑渲染。
