## 5. 简化版已锁定的设计

### 5.1 先定义的沙盒（中重量级）

```text
空间层   房间节点 + 连通边 + 设备锚点（不做网格/精确坐标）
设备层   状态机：类型/动作/参数约束/环境效应
环境层   每房间温度/湿度/光照，轻量差分演化，沿连通边传播
人物层   轻量：位置/活动/事件；persona 与偏好外部注入
时间层   统一虚拟时钟：tick / fast_forward / 事件调度
运行     snapshot / restore / replay / 并行副本 / 固定随机种子

不做：3D 物理、精确导航、自动 schedule、自动多设备编排、
      MCP 替模型解题
```

沙盒能力与任务族的对应：空间层→T1，设备状态机→T2，MCP 交互→T3，时间核→T4，人物事件/日志→T5，环境变量→T6。

### 5.2 六个任务族（每族 2~3 子项，均有示例与来源）

```text
T1 空间语义与连通（核心创新类）
   grounding / 连通传播与副作用 / 拓扑因果
T2 指令执行与鲁棒性
   单多设备组合 / 无效非法指令
T3 模糊、省略与指代理解
   模糊欠明确+隐性意图 / 省略与指代消歧
T4 时间、调度与环境动力学
   定时延迟持续 / 状态演化与目标验证
T5 长期记忆、个性化与多成员
   偏好形成修正 / 跨成员区分 / 主动服务时机
T6 环境感知与工具型信息获取
   环境传感器查询 / 部分可观测下决定查什么
```

横切特性：每类可配 valid/invalid；两种暴露模式（直接给全信息 vs 工具查询）；T1 工具模式下不预给拓扑，模型必须查 `query_topology`。

### 5.3 训练目标：四层（空间语义显式成层）

```text
L1 行为层（SFT）
   标准轨迹：观察→查空间/设备→执行→等待→验证
L2 空间语义理解与运用层（本论文核心训练层）
   a) SFT/RFT 空间推理链：连通→传播→目标设备/可行方案
   b) 预测验证奖励：先输出预期影响房间/副作用，由沙盒演化验证
   c) 方案选择奖励：选错拓扑方案给负奖励
L3 安全与合法性层（RL）
   不存在设备/越界参数/空间副作用惩罚
L4 长程效用层（RL）
   延迟成功、错误主动、打扰；累积效用 = 收益 − 干扰 − 成本
```

### 5.4 迁移：约 10 个接口、四个语义簇、三档适配

```text
观察/定位簇：observe_home、query_topology、inspect_room、
             find_devices、inspect_device
执行簇：execute_device_action
等待/验证簇：wait_for_event、query_events、check_goal_state
记忆簇：memory_read、memory_write

沙盒与 Home Assistant 各实现一套 MCP，工具名单与语义相同。
迁移实验按三档报告：零适配 / 仅 schema 适配 / 少量示例适配；
报告成功率保持、非法动作率、工具调用数、适配修改量。
```
