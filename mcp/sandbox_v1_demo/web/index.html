Sandbox V1 浏览器 2D Demo

这个页面展示的是我们目前的首版沙箱原型：房间、人物、设备、环境变量、暂停点，以及基于暂停点的 Gym-friendly step 语义。

这三个按钮对应的是一个“暂停点到暂停点”的沙箱流程，而不是普通网页按钮。 `重置场景` 会回到初始世界； `开启空调，并推进到下一个暂停点` 表示模型在当前决策点执行一个动作，然后时间控制核自动把世界推进到下一次需要停下来的时刻； `不做动作，继续推进到下一个暂停点` 则表示本轮模型选择 no-op，只看世界后面会发生什么。
