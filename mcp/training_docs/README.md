# 训练资料目录

本目录集中保存“沙箱建成后如何训练模型”的分析和可执行参数规格。它与 `mcp/doc/` 的分工如下：

```text
mcp/doc/
  研究方向
  投稿创新点
  沙箱和接口总设计

mcp/training_docs/
  模型训练路线
  显存与硬件分析
  SFT / DAgger / DPO / OPD / RL 参数
  数据格式、reward、实验矩阵
  训练结果和后续复盘
```

当前文件：

```text
1_沙箱建成后的模型训练路线_SFT_OnPolicy蒸馏与强化学习.md
  说明沙箱适合产生哪些训练信号，比较 SFT、学生在环模仿、
  OPD、DPO、GRPO、RLOO 和 PPO，并给出总训练路线。

2_单卡60GB_OPD训练参数与资源分析.md
  面向一张 60GB 显存 GPU，区分公开 OPD 论文的多卡配置与
  单卡最小可行配置，给出模型对、参数、显存预算、时间估算和降级规则。

3_智能家居智能体新方法与研究空间.md
  从真实家庭痛点出发，分析并发自动化冲突、错误/失效自动化、
  舒适与能耗折中、照护与隐私、权限与设备可用性等问题；
  明确哪些能由 SimuHome 落地为任务、状态、指标和论文方向。

4_从三条到六条_智能家居研究创新扩展方案.md
  以原有“空间环境、长期服务、虚实迁移”三条创新为基础，分析
  自动化诊断修复、家庭能源灵活调度、家庭安全事件响应
  三条新增创新应如何定义，如何避免重复现有研究，以及应拆成哪些论文。
```

文档使用顺序：

```text
先读 1
  判断该做哪一种训练
    ↓
再读 2
  根据单卡 60GB 资源选学生、教师和实际训练参数
    ↓
再读 3
  判断后续方法论文或第二阶段 benchmark 应该切入什么问题
    ↓
再读 4
  判断原有三条创新若扩展为六条，哪些是主贡献、支撑线或下一篇论文
    ↓
沙箱满足训练门槛后
  新增 5_数据集规格.md
  新增 6_首轮SFT实验记录.md
  新增 7_学生在环纠错实验记录.md
```

当前不建议先创建 OPD、GRPO 或 PPO 的正式训练代码。先让沙箱满足确定性、事件日志、任务 verifier、snapshot/replay 和可并行副本要求，再固化参数。
