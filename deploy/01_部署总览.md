# 01：部署总览

这组文档面向"拿到本仓库、想在自己机器上跑起来"的开发者。仓库提供三层能力，按需组合，互相不强制依赖。

```text
层1  MCP server ↔ 你的 HA                     需要：一个能访问的 HA + 长期令牌
     ha_mcp_universal\ 暴露 8 个统一语义工具
     不改 HA 源码、不要求特定安装方式（Docker / HA OS / venv 都行）
     → 02_快速开始-MCP连接自己的HA.md

层2  模拟家庭沙盒                             需要：Docker + Python + Mosquitto
     SimuHome :8000 → 发布器 → MQTT :1883 → HA 自动发现 25 个实体
     → 03_沙盒全链路部署.md

层3  米家真机接入                             需要：米家账号 + 上游 xiaomi_home 集成
     HA 装 HACS + XiaoMi/ha_xiaomi_home → 真机进 HA → MCP 认领
     → 04_米家真机接入.md
```

## 仓库里有什么

```text
ha_mcp_universal\            v2 主线：MCP server（8 个工具：观察/控制/时间/记忆）
ha_mcp_server\               v1 冻结版（论文主实验口径，保持不动）
simuhome_mqtt_publisher\     SimuHome → MQTT → HA 的桥：broker 配置、发布器、改名脚本
old_simuhome_bridge_project\ 早期桥接工程（历史参考）；compose.yaml 是本机历史版本
deploy\                      这组部署文档 + 通用版 HA 容器 compose
_tools\                      一键脚本 start_simuhome_stack.ps1 与若干本地工具
finally new paper\           设计文档与论文整理（11/14/15 号是接口与设计口径）
```

## 仓库里没有（需要在目标机器上生成或从上游获取）

```text
SimuHome 上游源码     https://github.com/Mr-luo-q/Simuhome_experiment（我们实测 f8a813f）
                     论文官方仓库是 holi-lab/SimuHome，但它不含 home_full.json
HA 配置目录           compose 挂载到 /config 的目录；首次启动后自动生成
HA 长期令牌           在 HA 界面里创建，存成单行文件 _secrets\ha_token.txt（不入库）
MQTT 账号密码         broker\make_credentials.ps1 生成（两个文件都被 .gitignore 排除）
大文件/论文 PDF       source.md 里登记了来源与体积，不随仓库分发
```

## 环境要求

```text
Python       3.13（SimuHome 要求 >=3.13；MCP server 要求 >=3.11，3.13 同时满足）
Docker       Docker Desktop（层2 的 HA 容器）；HA 也可用你自己的现成实例
Mosquitto    层2 的 MQTT broker（从 mosquitto.org 下载；Linux apt / brew 均可。
             本机 _tools\mqtt\ 留存的安装包不入库，新克隆的仓库里没有）
PowerShell   一键脚本是 Windows PowerShell 版本（本机实测平台）；
             Linux / macOS 按文档里的等价命令手工执行即可
```

## 端口约定

```text
8123   HA Web 与 API
8000   SimuHome 仿真 API
1883   MQTT broker（Mosquitto）
—      MCP server 走 stdio，不占端口；可选 HTTP 模式默认 127.0.0.1:8765
```

## 建议的阅读顺序

只接真机：`02` → `04`；复刻沙盒：`02` → `03`；遇到问题看 `05_常见问题与排错.md`。
