## 症状对照表

```text
症状                         先查哪里
HA 容器拉不起来              镜像 ghcr.io 需要网络/代理（Docker Desktop 里配 proxy）
HA 打不开 8123               容器状态、端口占用（netstat -ano | findstr 8123）
broker 起不来                password_file 缺失 → 先跑 make_credentials.ps1；
                            看 simuhome_mqtt_publisher\logs\mosquitto.log
HA 里没有 simuhome 实体      发布器日志 logs\publisher.console.err.log；HA 的 MQTT 集成是否已连接
实体全部 unavailable         顺序查：broker 进程 → health_check → 发布器 → HA MQTT 集成重连
SimuHome 房间数 0            仿真没载入 home；跑 start_simuhome_stack.ps1 -ResetHome
execute_action verified=false 命令被收下但没落地；多数是设备/仿真没载入或云端延迟
LOG 里 401/认证失败          发布器的 credentials 与 broker 的 passwd 不同步 → 重新
                             make_credentials.ps1 -Force，并同步改 HA 的 MQTT 集成
```

## 网络：容器怎么连宿主 broker

```text
Windows Docker Desktop     broker 监听 127.0.0.1:1883，HA 容器用 host.docker.internal 即可
Linux Docker Engine        容器访问不到宿主回环；两种做法：
                           ① mosquitto.conf 的 listener 改成 0.0.0.0 并加防火墙规则
                           ② compose 里加 extra_hosts: ["host.docker.internal:host-gateway"]
                              （HTTP 代理之外的方式，指向宿主地址）
云服务器/局域网             注意安全组与防火墙；broker 不要裸露公网
```

## PowerShell 相关

```text
脚本执行策略报错     用 powershell -NoProfile -ExecutionPolicy Bypass -File <脚本>
中文显示乱码/.ps1 报错  .ps1 要存成带 BOM 的 UTF-8（PowerShell 5.1 按本地代码页读文件）
路径带空格           全部加引号；脚本内部已用 Join-Path，不要在配置里手拼字符串
```
